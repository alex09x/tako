П1Промпт (r2-01, r2-04) — показывает юзера вместо каталога
1. «alex09x» — это basename($HOME), формально каталог. Но home обязан сокращаться до «~». Правило: cwd == $HOME → «~»; внутри home → basename («tako-core»); ssh → host. То же для заголовка вкладки (там «~» уже правильно — значит, логика тайтла и промпта разошлась, унифицировать в одну функцию).
2. Скобка-уголок не та. Рисуется фигурная «⎰»-образная. Спека: ╭ (U+256D) и ╰ (U+2570), цвет #8A7F76.
3. Символ ввода. Выглядит как «)». Должен быть ❯ U+276F ember (проверить, что не подменяется шрифтом; если fish — set fish_prompt, наш хук и так его ставит).
4. Мета успеха: «· 20s · ✓» — галочку убрать. Спека: успех = только длительность #8A7F76; ✘ + код красным — только при ошибке. Галочка — шум.
5. Формат «20.0s» в выводе — ок (это программа), но мета промпта и таб обязаны показывать «20s» (10–59s → целые; <10s → одна десятая; ≥60 → «1m 23s»).

1. inverse не инвертирует. Слово «inverse» выглядит как обычный текст. SGR 7 обязан поменять fg↔bg (блок светлого фона с тёмным текстом). Проверить в рендерере флаг INVERSE до выборки цветов.
2. Bright-ряд свотчей не видно. printf печатает 40–47m и 100–107m, а на экране одна полоса. Вторая строка должна рендериться такими же квадратами с рамкой rgba(250,247,242,0.15).
3. dim слишком тёмный? «dim» едва читается. SGR 2 = fg с alpha ~0.55 на нашем фоне, не 0.3.
4. Лигатуры. Разлеплены — для терминала это ПРАВИЛЬНО (курсор по ячейкам), решение зафиксировано: лигатуры не включаем. Пункт из README закрыт.
