ПРАВИЛА ПОВЕДЕНИЯ
когда бежит: только если команда идёт >3s (по OSC 133 C→D) — короткие ls/cd не дёргают глаз
после exit 0: в активной вкладке зелёный на 2s → обратно в покой; в фоновой — держится до переключения на неё
после exit ≠ 0: дрожь один раз (0.4s), красный держится до фокуса вкладки; точка = непрочитанное
приоритет: призрак > ошибка > работает > BEL > успех > покой (если состояний несколько)
reduce motion: анимации выключаются, остаётся только смена цвета
клик по крабу: меню — повторить команду · скопировать вывод · kill процесса · reconnect (для призрака)
iOS: тот же краб в шапке сессии; в списке сессий — вместо цветной точки
