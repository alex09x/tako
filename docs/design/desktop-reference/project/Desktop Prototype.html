Спека рабочего поля

слова
Workspace — группа сессий. Сессия — строка в сайдбаре со своим полем (в нативном Tako — вкладка). Терминал — один шелл внутри сессии (pane): ⌘N делит текущий, ⌘T открывает новую сессию.
первый запуск
Мастер выезжает листом поверх первого живого терминала, текст — системным шрифтом, терминальное — моноширинным. Предложение макета: 5 шагов вместо нативных 7 — Привет (логотип, одна фраза, живой терминал, «Начать») → Тема → Агенты → Доступы → Готово; «Командная строка» стала строкой «takoctl в PATH» в блоке навыка на шаге «Агенты», «Уведомления» — карточкой в «Доступах». «Готово» — знак готовности, «Tako готов», факты (тема, у кого навык, что выдано) и одно действие «Начать работу»: закрывает мастер и фокусирует уже открытый терминал. Невыданные необязательные доступы — не ошибка. «Закончить позже» на каждом шаге, по названиям шагов можно прыгать, выбранное сохраняется; вернуться — ⌘, › «Мастер настройки…».
темы
Каталог макета — 24 темы: тёмные, светлые, мягкие, контрастные (это предложение, не набор нативной 526). В мастере подборка из 8 карточек с живым образцом терминала и палитрой, «Как в системе» и «Все темы» с поиском и фильтрами. В Настройки › Оформление тот же поиск и фильтры над сеткой пресетов. Выбор сразу меняет терминалы; пресет по-прежнему целиком (цвета, шрифт, размер), наследование и сброс не меняются.
агенты
«Найдены на этом Mac»: иконка, имя, «● Статусы встроены» — у Claude Code, Codex, Antigravity, Qwen, Muse статусы встроены (OSC 7501), установка не нужна; найденный бинарник — ещё не подтверждение живого статуса. Ненайденные поддерживаемые — одной строкой ниже. Блок «Агент может управлять Tako» (открыть терминал, окна, вывод через takoctl) с одним действием «Добавить навык найденным агентам»: без повторного подтверждения, уже добавленным не ставим, после — «Добавлено: …». «Что меняется» раскрывает детали: takoctl skills install, CODEX_HOME, adapter gemini для Antigravity, удаление только наших старых хуков, Gemini CLI на хуках. Изображения Claude Code, Codex, Antigravity и Gemini CLI — те, что Tako уже показывает (Agent*.pdf, выгружены через AppKit); Qwen Code — логотип из репозитория QwenLM/qwen-code; у Muse Code официального знака не нашли — нейтральный символ терминала и название.
доступы
Самопроверка: при открытии раздела и после возврата из Системных настроек Tako перечитывает то, что macOS отдаёт без вопросов. Уведомления (UNUserNotificationCenter: статус + баннеры/звук/наклейки) и Микрофон (AVCaptureDevice) — точно: «Доступ выдан · Настроить», отказ — «Выключено в macOS · Открыть настройки», не спрашивали — «Включить»/«Разрешить». Запись экрана (CGPreflight) — только да/нет: «Нет доступа или ещё не спрашивали · Запросить». Папки — только по явной кнопке «Проверить» (чтение может само вызвать вопрос macOS), итог по каждой: Рабочий стол / Документы / Загрузки. Полный доступ к диску, Локальная сеть, Системный звук, Управление приложениями — публичного API нет: «Проверяется в macOS · Открыть настройки», без зелёной галочки. Интернет ≠ локальная сеть, одна папка ≠ полный доступ к диску, права Tako ≠ права других процессов и удалённых хостов. Одна строка пользы, детали API — по «?». Системные окна в макете подписаны как макет; браузер права не проверяет. Демо: кнопка «доступы: …» переключает состояние macOS.
глобальная клавиша
Универсальный доступ нужен только для Quick Terminal из любого приложения: включил в Настройки › Доступы → вопрос macOS → Системные настройки, Tako замечает выдачу. ⌘⇧` внутри Tako работает и без него. Первому терминалу доступ не нужен. Переключатель в Настройки › Доступы — новый UX: в нативном Tako такого места пока нет.
карта
Кнопка «карта» в демо: все точки входа с «показать →» и список того, что в Tako есть, а в макете ещё нет (Quick Terminal, палитра ⌘⇧P, поиск, takoctl ask и overlay-формы, Secure Input, восстановление сессий).
ssh
Форма «Подключиться по SSH…» в «+» — новый UX: в нативном Tako на Mac готовой такой формы нет, ssh запускается командой в терминале.
путь к результату
Дизайн-предложение, в нативном Tako ещё нет. Один путь: Обзор ⌘⇧O (снимок всех терминалов, сначала кто ждёт и где упало; ⏎ — ровно в эту панель) → ⌘F в терминале (команды с #N и exit-кодом, «Команды / Весь текст», «С ошибкой», ⏎ выбирает) → выбранная команда (копировать команду / вывод / только ошибку, закрепить) → «Отчёт / Diff / График / Снимок рядом» ⇧⌘↩: результат открывается обычной панелью той же сессии с подписью «из #N», «Текст» показывает исходник → Esc закрывает результат и возвращает к #N, ещё Esc — к приглашению, фокус в том же терминале. Одна идентичность «#N команда» везде; переход никогда не перезапускает команду. Демо: сессия «tako-core tests», #4 mitts test --workspace → exit 101 → отчёт → «правка этого файла · git diff #3»; #1 mitts bench — график, #2 takoctl screenshot — снимок.
сайдбар
Всегда виден, 248 pt, тянется за правый край 200–380, двойной клик по краю — сброс. Шапка: светофоры и справа три иконки — клавиши (?), настройки (⌘,) и «+» (новая сессия, новый терминал, SSH, workspace). Нижней строки нет: список сессий идёт до самого низа. Под шапкой поиск (⌘K или /) и фильтр All / Needs you · N.
внешний вид
Тема = палитра терминала (фон, текст, 6 ANSI-цветов). Сайдбар, терминалы, меню и плашки выводятся из неё автоматически, поэтому подходит любая тема в формате Ghostty / iTerm2. «Как в системе» — пара тем: тёмная и светлая, переключается вместе с macOS. Цвета статусов (Ember, Claw, зелёный, красный) от темы не зависят — статус узнаётся всегда.
наследование
Оформление терминала идёт по цепочке Общие → workspace → терминал, как в нативном Tako (global → workspace → pane); сессия — только контекст терминала. Уровень либо выбирает пресет (цвета, шрифт и размер целиком), либо переопределяет отдельные поля в «Настроить…»: шрифт, размер, фон, текст, курсор. Выбор пресета сбрасывает свои поля этого уровня; ↺ удаляет переопределение, а не копирует значение родителя. Сверху крошки «Для: Общие › ● Infra › терминал psql в сессии prod-db», у уровня со своими настройками метка «своё». Подписи полей: «Наследуется от «Infra»», «из пресета Gruvbox», «● Своё · ↺ сбросить». Правый клик по workspace или терминалу → «Оформление…»: настройки открываются строго по центру окна Tako и не прыгают при смене вкладки или уровня; редактируемый терминал обведён Claw, результат виден в превью вверху настроек. На маленьком окне высота подстраивается, содержимое прокручивается. Сохраняется сразу, кнопки «Применить» нет. Терминалы, сайдбар и клавиши — общие настройки приложения, без выбора уровня. Перенос сессии в другой workspace: терминалы без своего пресета сохраняют прежний вид. Сайдбар и поле — по общей теме, чтобы ничего не мигало. В демо workspace Infra на Gruvbox.
настройки
Неактивные терминалы: как есть / тусклее (по умолчанию, текст 72%) / сильно (50%) — тот, в котором печатаешь, всегда яркий. Терминалы сессий в сайдбаре: раскрыты у всех (по умолчанию) или только у открытой; ▸ у сессии запоминается. Шрифт терминала 11 / 12.5 / 14, куда делить новый терминал (авто / справа / снизу), строки сайдбара (две / одна), ветка git, порты, анимации (все / без), уведомления. Применяются сразу.
группы
Клик по заголовку — свернуть. Наведи: «+» новая сессия здесь, «⋯» меню (переименовать, цвет, удалить пустую). Клик по точке — цвет. Двойной клик по имени — переименовать. Новая группа — «+» в шапке → «Новый workspace»; внизу списка ничего нет.
сессия
Кольцо 1b, имя, Claw-точка «есть новое», число терминалов. Вторая строка: вопрос агента (Claw), «exit N · терминал» (красным) или папка · ветка · порт. Без таймеров. ▸ раскрывает терминалы сессии. Наведи — ✕ закрыть; если что-то работает, подтверждение прямо в строке.
перетаскивание
Сессию можно тащить: Claw-линия показывает место, бросил на заголовок группы — переехала в эту группу.
правый клик
Сессия: открыть, переименовать (F2), новый терминал, переместить в группу, показывать ветку / порты, отметить прочитанным, закрыть. Терминал: фокус, отлепить, свернуть, закрыть.
клавиши
↑↓ курсор по сессиям, ⏎ открыть, ← → свернуть/раскрыть терминалы, F2 переименовать, ⌥⏎ следующий, кто ждёт, Esc сбросить.
офлайн
Пунктирная рамка и кольцо, текст тусклый, во второй строке «переподключить».
шапка терминала
28 pt, без линии. Кольцо статуса, имя (команда или агент), папка — только если её нет в имени. Справа число только у ошибки: «exit 101». Чипов нет: «ждёт» и «работает» видно по кольцу и рамке. Кнопки — свернуть, отлепить, закрыть — появляются при наведении поверх правого края. Двойной клик — развернуть. Правый клик — переименовать, разделить вправо (D) / вниз (⇧D), развернуть, отлепить, свернуть, закрыть. У отлепленного терминала из другой сессии после имени «· сессия».
поверхность
Сайдбар, поле и верх — один цвет #14100E, без линий. Терминалы #1C1714, скругление 10, зазор между ними и до краёв 8.
по умолчанию — сетка
Терминалы сессии делят поле без перекрытий (дерево сплитов). Новый терминал делит текущий: слева-справа, если хватает ширины (2×360+8), иначе сверху-снизу.
граница сплита
Зазор 8 между терминалами — ручка. Наводишь — Claw-линия 2px, тянешь — меняется доля, соседи двигаются вместе. Мин. терминал 360×200.
перетащить
Тянешь терминал за шапку — он выходит из сетки, остальные смыкаются. Подсветка показывает, куда сядет: край другого терминала = сплит с ним (лево/право/верх/низ), край поля = вся сторона поля. Отпустил вне подсветки — терминал остаётся поверх.
плавающее окно
Кнопка «⧉ Плавающее» в шапке (и «Плавающее окно» в правом клике, клавиша P): терминал выходит из сетки и висит поверх, с тенью, ресайз с 8 сторон. Он виден во всех сессиях; в шапке метка, из какой он сессии. «В сетку» — встаёт обратно в сетку текущей сессии; при следующем «Плавающее» возвращается на своё прежнее место. Бросил его на край терминала в другой сессии — переехал туда.
свернуть
Кнопка — : терминал улетает в правый нижний угол и становится плашкой-заголовком 30 pt (кольцо, имя, папка). Плашки лежат поверх поля и не отнимают у сетки место. Сетка смыкается. Клик по плашке — терминал возвращается на своё прежнее место.
развернуть
⤢ или двойной клик по шапке: терминал на всё поле поверх сетки, скругление остаётся. Повтор — назад в свою ячейку.
закрыть
140 мс; соседи забирают место. Если процесс работает или агент ждёт — сначала вопрос внутри терминала.
статусы
Прогресса нет: терминал не знает, сколько осталось команде, поэтому идущая команда — «работает». Семья 1b + 5a на всех поверхностях (строка сайдбара, терминал, плашка свёрнутого): работает — комета по рамке 2.2 s и кольцо 0.9 s; ждёт — Claw-рамка дышит 1.6 s, свечение 16 px 30%; готово — зелёный блик 0.9 s один раз, кольцо подпрыгивает, потом тихо; ошибка — красная линия 2 px снизу, дрожь 0.4 s один раз, «exit N»; живёт — тусклое Ember-кольцо в тишине, волна на каждую порцию вывода, без скорости; офлайн — пунктир. Приоритет: офлайн > ошибка > ждёт > работает > готово > живёт > покой. Reduce motion: без движения, статичные рамки.
уведомления
Только для невидимого: терминал свёрнут, закрыт другим или в другой сессии. Тост 4 s, клик ведёт к терминалу.
